# Vikash Sinha Portfolio

Source code for [vikashsinha.dev](https://vikashsinha.dev), the personal portfolio of Vikash Sinha, a B2B marketing leader and product builder.

## What this portfolio shows

- Recruiter-first career story, résumé and selected commercial outcomes
- B2B growth, demand generation, CRM and revenue-system positioning
- Product work including QueryCite
- Writing from the *Inside the Buying Committee* newsletter
- Responsive pages for About, Services, Products, Blog and Contact

## Stack

- Next.js and React
- TypeScript
- CSS
- Vite / Vinext

## Run locally

```bash
npm install
npm run dev
```
