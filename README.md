# Vikash Sinha Portfolio

Source code for [vikashsinha.dev](https://vikashsinha.dev), the personal portfolio of Vikash Sinha, a B2B marketing leader focused on growth, brand and revenue.

## What this site includes

- Recruiter-first homepage with career outcomes and selected operating stories
- Detailed About page with experience, skills and achievements
- Links to LinkedIn, GitHub and the *Inside the Buying Committee* newsletter
- Responsive layout for mobile and desktop

## Technology

- Next.js and React
- TypeScript
- CSS

## Run locally

```bash
npm install
npm run dev
```
